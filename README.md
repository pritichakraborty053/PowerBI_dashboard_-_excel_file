# PowerBI_dashboard_-_excel_file
Analysis of a large data of a Superstore by using excel and created a dashboard using Power BI
Superstore Sales Performance & Profitability Dashboard
An end-to-end business intelligence project analyzing 4 years (2011–2014) of retail sales data using Microsoft Excel and Power BI. Covers $2.3M in revenue across 5,009 orders with insights on regional performance, category profitability, seasonal trends, and actionable business recommendations.
